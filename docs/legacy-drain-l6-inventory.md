## Callback completeness note

Every anonymous callback in the source belongs to its enclosing row above:
array iteration and view-factory callbacks are H/G/F composition callbacks;
DOM `onclick`/`oninput`/`onkeydown`, timers, animation frames and all five
`popstate`/`load`/service-worker listeners are I/C/D/B adapters. There are no
additional top-level facade entries or independently owned state blocks.
